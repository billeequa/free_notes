Jnotes 1.3

- Shorter editor header; save status appears when there is something to report.
- Swipe between Notes and To-do. Swipe a task right or check its box to complete it.
- All, Open, Completed, and Flagged filters in a submenu; cleaner task cards.
- Open tasks show Added; completed tasks show Completed.
- Snow, Rose, Lavender, and OLED black themes added.
- Notes and tasks automatically write to the same selected folder.
- Updates in Settings, including GitHub Releases and APK validation. No recovery feature.

The existing to_do_jnotes.txt format is preserved. An in-place update keeps the selected folder. If migrating from a debug APK signed with another key, first verify your notes and to_do_jnotes.txt in the selected external folder; a reinstall will require choosing that same folder again. This release establishes a permanent signing key; keep its private setup archive safe.

The repository is private. Use Open GitHub Releases and sign in to download. Direct in-app checks/downloads require a public release repository.
