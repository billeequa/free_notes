# JNotes 1.5.3 — simpler account setup and sign-in

- Create your JNotes password on the website once: choose **First time? Set up my password**, open the emailed link, choose a password, and save the recovery code.
- Sign in on the phone and website with the same email/password. Normal sign-in sends no email and requires no numeric code.
- Invitation and reset links now open the correct setup/recovery screen. Expired links and email rate limits have clear messages.
- Phone Settings links directly to password setup and recovery on the current website. The connection still updates automatically when hosting changes.
- Existing encrypted notebooks, local files, pending edits and signing identity are preserved. Password recovery keeps the original notebook key and recovery code.

Install **jnotes-26.apk** over the existing app; no uninstall is needed.
